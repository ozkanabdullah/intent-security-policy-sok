# Intent-Driven Security Policy Automation — SoK

This repository is being prepared to accompany the paper *Proactive, Robust Security at Scale: A Systematization of Intent-Driven Security Policy Automation*.

## Scope

The study maps research on four stages of intent-driven policy automation: Intent Capture, Intent Translation, Policy Enforcement, and Policy Assurance. It examines both general intent-based networking and security-oriented work.

## Repository status

The reproducibility package is under preparation and validation. Its planned contents include the search and screening protocols, coding rules, study-level data, analysis scripts, and exported tables. A verified release will identify the files and instructions needed to reproduce the reported results.
