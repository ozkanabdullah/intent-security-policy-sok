# Intent Capture: study-level coding

This folder contains the study-level Intent Capture coding behind *Proactive, Robust Security at Scale: A Systematization of Intent-Driven Security Policy Automation*. Category definitions and decision rules are in the [codebook](../../Codebook/README.md).

| File | Content |
|---|---|
| `README.md` | Column definitions, notation, and the coding table |
| `intent_capture.csv` | The same table in machine-readable form |

## Coverage

The table lists 111 studies: 75 from the general intent-based networking stratum and 36 from the security-oriented stratum. One general study, `ojaghi2026intentbased`, is omitted because its intent is machine-originated and has no human input channel, so it receives no Capture mechanism. Rows are sorted by paper title.

## Columns

| Column | Content |
|---|---|
| BibTeX Key | Key of the study in the paper's bibliography |
| Paper | Title, authors, venue, and year |
| Sub-Corpus | `General` or `Security` (the security-oriented stratum, marked `§` in the paper) |
| Capture Family | One dominant family per study |
| Sub-Mechanism | One value per study, except within LLMs, where co-occurring values are separated by semicolons |
| IR Family | One dominant intermediate representation per study |
| Rationale and Evidence | The basis for each decision, with verbatim quotations from the source. Lines are labelled `Family`, `Sub`, `IR`, and `Evidence`, with optional `Secondary` (a serious alternative that was not counted) and `Note` lines |

## Notation

| Value | Column | Meaning |
|---|---|---|
| (not specified due to lack of evidence) | Sub-Mechanism | The family is identified, but the source does not give enough detail to determine the sub-mechanism |
| (no matching sub-mechanism) | Sub-Mechanism | The mechanism is described, but it fits none of the listed sub-mechanisms of its family |
| (not applicable) | Sub-Mechanism | No family is assigned, so no sub-mechanism can be assigned |
| Not specified | Capture Family | The intent is human-originated, but the source does not describe how it is captured |
| Not specified | IR Family | The source does not describe the artifact handed to Translation |
| Not applicable | IR Family | Capture produces a label from a closed set, and no later stage consumes it |

In the paper's Capture table, both "(not specified due to lack of evidence)" and "(no matching sub-mechanism)" appear as `†`.
